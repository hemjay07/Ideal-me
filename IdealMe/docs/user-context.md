## APP REQUIREMENTS & PHILOSOPHY

### Core Philosophy
- **Most Important Feature:** Self-improvement/self-iteration
- **Essential:** Data gathering and analysis
- **Vision:** App that understands him and provides perfect assistance over time
- **Can Start:** Simple, but must have foundation for self-improvement
- **Goal:** Like a living human actively gathering information about him

### What Would Make Him Use It Daily
**Must Have:**
- Highlight important articles, resources, videos
- Surface Twitter bookmarks at right time
- Track courses to continue
- Manage incomplete tasks (bots to build, important work)
- Blow his mind by being a perfect assistant
- Show information that will benefit him

**Must Avoid:**
- 50 features (way too much, definitely overwhelming)
- High friction (manual exports, too many steps)
- Generic productivity advice (needs personalization)
- Rigid schedules (doesn't work for him)

### Notification Philosophy
- **Current Knowledge:** Zero idea how notifications should work
- **Approach:** Test different strategies, gather data, analyze, improve
- **Critical Feature:** Self-iterating based on usage data
- **Requirement:** Would block other app notifications to make this work
- **Possibility:** Route important notifications from other apps to IdealMe

### Technical Preferences
- **Storage:** Local is fine (so long as syncs to phone)
- **Privacy:** Not concerned (personal app, not public)
- **Speed:** Not in rush, doesn't care how long build takes
- **Quality:** Wants it done right, not fast

### Self-Improvement Implementation
**Critical Questions:**
- How to actually implement self-improvement?
- How to make it work effectively?
- This is THE moat of the app

**Desired Flow:**
1. App analyzes its own usage
2. Comes up with improvements
3. Asks user for new features
4. When given go-ahead, builds it
5. If too much overhead, user can build updates
6. Must ensure continuous improvement

**Philosophy:**
- Should be self-aware
- Like autonomous agent that evolves
- Data-driven decisions
- User approval on major changes
